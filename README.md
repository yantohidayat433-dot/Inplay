# Никита Иванов

Одностраничное портфолио AI-креатора. Один `index.html` без сборки, изображения и обложки в `images/`, ролики в `videos/`. Короткий скрипт добавляет запуск по обложке и ставит предыдущий ролик на паузу. Публикуется через GitHub Pages из ветки `main`.

Дизайн-система (шрифт, кегли, цвета, сетка, отступы, наведения) описана в `UI-KIT.md`. Меняешь токен в коде, обнови и его.
